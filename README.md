## ✦ About SMRITI

SMRITI is an AI-powered cognitive-care platform designed to make cognitive engagement more personal, accessible, and culturally relevant. It transforms meaningful life experiences into interactive activities while helping caregivers understand participation and individual activity patterns.

## ✦ Core Features

### 🧠 Memory Universe
Organize personal photographs, familiar people, places, stories, and everyday memories in one meaningful space.

### 🎮 Personalized Cognitive Games
Explore photo recall, object matching, story sequencing, and daily routine activities inspired by familiar experiences.

### 📊 Cognitive Fingerprint
Track individual activity patterns against personal history to support personalized recommendations.

### 💚 Care Pulse
Provide caregivers with understandable activity insights and recommendations for supportive engagement.

### 🌿 Culture DNA
Promote culturally relevant experiences and regional-language accessibility.

### 📶 Offline-Friendly Experience
Designed to support core activities in environments with limited internet connectivity.
